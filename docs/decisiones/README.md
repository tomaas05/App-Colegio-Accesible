# Registro de decisiones técnicas

Una decisión por archivo, numeradas (`0002-titulo-corto.md`, …). Cada una con: estado, fecha, responsable, contexto, decisión, alternativas descartadas y consecuencias. Copia [0001-stack.md](0001-stack.md) como plantilla.

Se escribe una cuando la decisión afecta a más de un objetivo o es difícil de deshacer (modelo de usuario, cómo se calculan los estados, cómo se aplica el perfil visual…).
