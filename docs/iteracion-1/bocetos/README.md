# Bocetos

| Archivo | Qué es |
| --- | --- |
| `despega_mockup_v3.html` | Versión vigente del mockup navegable, todas las pantallas en un archivo. Se abre con doble clic en el navegador. |
| `despega_mockup.html` | Versión anterior, se conserva como histórico. |
| `despega_contexto_mockup.md` | Decisiones de diseño y contexto del mockup. |

Las variables de color y tipografía del mockup son las que usa la aplicación en `static/css/tokens.css`. Si cambian aquí, hay que cambiarlas también allí.

El mockup carga Google Fonts porque es un boceto; la aplicación real sirve las fuentes desde nuestro servidor (RNF1.1.2).
